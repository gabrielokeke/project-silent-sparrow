📰 Live Sports & Anime News Dashboard

A sleek, responsive real-time dashboard delivering the **latest sports and anime headlines** using **Bright Data’s Web Unlocker and Scraper API**. Built with ❤️ using HTML, CSS, and JavaScript (or React).

 🚀 Features

- ⚡ Real-time scraping of trending sports & anime news
- 🎨 Stylish UI with smooth transitions and hover effects
- 🧠 Categorized by type: Sports, Anime, etc.
- 📱 Fully responsive (desktop/tablet/mobile)
- 🧭 Pagination, filtering, and error handling
- 🌐 Built for the [Bright Data AI Agents Challenge](https://brightdata.com/challenges/devpost)


 🛠️ Tech Stack

| Tech         | Usage                          |
|--------------|--------------------------------|
| CSS          | UI structure & styling         |
| JavaScript / React | Frontend logic & rendering |
| Bright Data  | Real-time web scraping         |
| Netlify      | Deployment                     |

 🌈 Local Setup

1. Clone the repo:
   git clone https://github.com/gabrielokeke/project-silent-sparrow.git
   cd silent-sparrow

2. Install dependencies
   npm install

3. Run the app locally:
  npm run dev
